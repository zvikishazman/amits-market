# Contributing

## Development workflow

1. Create a focused branch from `main`.
2. Install the locked dependencies with `npm ci`.
3. Keep secrets in the ignored `.env` file; never commit credentials or user data.
4. Run `npm run lint`, `npm test`, and `npm run build` before opening a pull request.
5. Explain the user-facing behavior and include screenshots for interface changes.

Keep pull requests small enough to review and avoid unrelated formatting changes.
